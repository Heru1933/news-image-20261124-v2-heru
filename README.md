THE TUESDAY EDITION — a broadsheet of Tuesday 24 November 2026. 40 stories,
all verified against BBC, Reuters, AP, Times of India, CNET and others, each
with its source printed beside it. Pure Python standard library renderer
(no Pillow): bitmap fonts, a raw-RGB still blitter, a small canvas and a
PNG encoder. Forest green and cream: a masthead naming the day, one
full-width hero (Nvidia reinstates Jensen Huang) with its toon
illustration, seven illustrated features in a 4 + 3 grid (COP31 no deal,
India's $1.6bn Nepal pledge, Alcaraz's ATP Finals title, the supermoon
meeting the Pleiades, the NHS AI screening trial, the White House
Christmas tree, Miley Cyrus's wedding), the other 32 stories as a numbered
list, and a stats strip (+$1tn Nvidia, 0 COP31 deal, $1.6bn to Nepal,
258 Democrat seats, 24 dead in the Java fire, 153 drones). The eight
illustrations are toon stills rendered from a Remotion + Three.js engine.
Fully deterministic — two runs write byte-identical PNGs.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024) to `MAKEFUN_OUTPUT_DIR` when set, otherwise to `output/`.
